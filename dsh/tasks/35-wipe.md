# 任务 35:认出全灭，过掉全灭画面，按游戏实际的处理报告

范围:
- 只改 `src/engine/`(主要是 `skills/battle.ts`、`game.ts`)和 `test/`;
- 不改 `package.json`、`tasks/`、`lib/`、`../agent/`、`../bridge/`、`../deploy/`;
- 不碰 git;不运行 `npm run build`。
- **不运行 `scripts/web.sh`、`scripts/ask.mjs`,不连笔记本。** AI 正在笔记本上玩 FF5。测试用假 pilot,写法照 `test/battle.test.ts`。

## 起因(11-03 真机，FF5 北山)

1. **全灭以后一直卡着。**
   - 队伍在北山洞窟(地图 229)的随机战里全灭了(敌人 3 只风筝猫)。桥插件读到四人 HP 都是 0,状态都是「无法战斗」，场景一直是 `Battle`。
   - `battle.fight()` 只在“有人能行动”或“战斗结束”时往下走，全灭画面上两样都没有，于是空等到 300 秒超时。
   - 超时以后,`regular()` 的 `judge()` 判成 `lost`,接着 `loadGame`。可这时游戏还停在战斗画面上，读档也读不成。
   - 下一个工具一进来又碰到战斗，再等 300 秒。结果 `advance_story` 每次 390 秒，`walk_to` 800 秒超时，`choose`、`set_tactics`、`inventory`、`look_around` 都是 320 秒超时。卡了 40 多分钟，玩家放弃了这一轮。
   - 首领战(`game.settle()` 的首领分支)也一样：玛基莎那一战四人都倒了，还是等到超时才报「战斗没打完:timeout」。
2. **这一作全灭以后不是游戏结束。**
   - Claude 在全灭画面上按了一两次确认，场景就从 `Battle` 回到了 `Player`,队伍被放回**这张地图的入口**:
     - 西侧山谷的哥布林战：回到 (15,68),全员满血;
     - 北山玛基莎：回到地图 232 的 (38,13),满血、中毒也好了;
     - 地图 229 的随机战：回到 (20,12),HP 只剩三到五成，还中着毒。
   - 存档次数和金钱都没变，也没有回到标题画面。
   - 所以 `regular()` 现在「全灭就读档」的做法不对：游戏没到标题画面，不该读档。

## 要做的

1. **`fight()` 认出全灭。**
   - 每一圈都看我方：活着的一个都没有(HP 都是 0,或者状态里有「无法战斗」)，就是全灭。数据从 `battleMenu` 或 sample 里取，用现有的读法。
   - 认出全灭后，**按确认，直到离开战斗场景**。最多按约 30 秒，用 `pilot.now()` 计时;每按一次先等一会儿，确认还在战斗里再按下一次。
   - 然后马上返回 `{ ok: false, error: "wiped", ... }`,不要等到 300 秒。
2. **全灭以后看游戏去了哪里(`regular()` 和首领分支都要)。**
   - 到了标题画面：照现在的做法读 `slot` 号存档;
   - 回到了地图上：**不读档**。照实报告，例如「全灭(敌人:风筝猫),游戏把队伍放回了地图 229 的 (20,12);巴兹 73/222[毒] …」。并提醒模型：先回复，再考虑回城补给、换策略或练级。
   - 两样都不是(还在战斗、读不到)：照实说卡在哪里，不要假装处理好了。
   - 把「这一作全灭不一定是游戏结束，可能放回地图入口」写进 `regular()` 上方的注释，带上日期和这三次的经过。
3. **首领分支(`game.settle()`)**:`fight()` 返回 `wiped` 以后，照第 2 条处理;工具结果写「首领战全灭」，不要写「战斗没打完:timeout」。`lastBoss` 记录也带上全灭。
4. 别的地方如果也会在战斗画面上一直等(比如 `waitFor` 卡在 battle),顺手查一下;改了的话在回报里列出来。

## 测试(假 pilot)

- 我方四人 HP 都是 0:`fight()` 在几秒(按假时钟)内返回 `wiped`,中间按过确认，没有等到 300 秒;
- 全灭后假 pilot 回到地图上:`regular()` 不调用读档，结果里有地图号、格子和队伍 HP;
- 全灭后假 pilot 到了标题画面：照旧读档;
- 首领分支全灭：工具结果写「首领战全灭」。

`npm run check` 全过，测试数不能比现在少(现在是 505 个)。
