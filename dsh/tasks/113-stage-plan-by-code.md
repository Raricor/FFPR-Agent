# 任务 113:长路径由代码驱动——坐标 go 也触发阶段计划，有计划时代码按计划一口气走

工作目录 `dsh/`。可以改 `src/engine/game.ts`、`src/engine/stage/`、`src/engine/route/`、`src/engine/prompt.ts`(只改讲 `go`/`route`/`plan_stage` 的那几行)、`src/plugin/config.ts`(只加本任务的 Config 项)、`test/`(含 `test/fixtures/prompt/` 里随提示词变的对照文件)。不碰 `src/engine/skills/move.ts`(任务 112 同时在改)、`../bridge/`、`../deploy/`、`../agent/`,不碰 git,**不连笔记本**,**不用 docker、不绕开沙箱**。

## 起因(11-10 真机，用户问“长路径怎么体现出来”)

- 整个活动日志里 `plan_stage` **一次都没被调用过**;`route` 只在卡纳克城用过 2 次(每次同一层 2 个宝箱);`go` 11-08 一天 505 次、11-09 224 次。新游戏开场模型照样 `terrain` → `entrances` → `go [175,140]`。
- 原因：长路径的两个开关都要模型自己碰。
  1. 自动叫阶段官(`stageBeforeTravel` 里 `stageAutoPlan`)只在 `go` 的目标是**地名/地图号**时才有 `destinationMap`;坐标 `go`(`toolGo` 的 `goCellTarget` 分支)只走 `stageBeforeGoCell`,而它在没有计划时直接放行。模型几乎只用坐标，所以从来没触发过。
  2. 有了计划，按计划走要模型调不带站点的 `route {}`(`stagePlanRouteStops`);`stageBeforeGoCell` 拦下坐标 `go` 后只回一段拒绝说明，模型还得自己再想一步。
- 用户定的方向(11-10):出发没备齐就硬拦;路径能用算法算就算好;JRPG 的很多思考可以提前做好，AI 介入要少;走路、开宝箱、战斗尽量不经过 AI 思考。

## 做法

1. **坐标 go 认出要去哪张图**:当前图上的目标格是(或紧挨着，距离 ≤1)一个已知出口/入口(atlas 里这张图的出口、或桥插件 `entities` 里的 `GotoMap`)时，把那张图当作这次 `go` 的目的地，照地名 `go` 一样先过 `stageBeforeTravel`(自动叫阶段官、出发检查、写理由放行)。认不出时行为不变。
2. **有计划时，被拦下的 go 改成按计划走**:`stageBeforeGoCell` 要拒绝时，改为直接执行计划剩下的路线(和 `route {}` 同一条代码路径:有路线进度就接着走，没有就用 `stagePlanRouteStops`),工具结果开头写一句“这个坐标不在阶段计划里，代码按计划接着走了”，并说明要离开计划就带 `leave_incomplete` 理由再 `go`。开关放 Config(默认开);关掉时保持现在的拒绝说明。
3. **出发后到了目的地就接着按计划走**:一次地名/入口 `go`(或第 1 条认出的坐标 `go`)通过出发检查、到达计划覆盖的地图后，如果计划还有没走完的站，同一次调用里接着执行计划路线，不再把控制交回模型。路线遇到剧情、首领、全灭、要模型决定的情况照旧提前返回(沿用 route 执行器的 `early` 规则)。开关放 Config(默认开)。
4. **阶段统计(验收用)**:阶段计划记录里累计：出发到完成期间模型调用的游戏工具总数、其中 `go`/`route`/`plan_stage` 各几次、代码按计划走完的站数、用时。计划完成(或被新计划替换)时往活动日志写一行「阶段统计「X」:工具 N 次(go a、route b),按计划走了 c 站，用时 m 分」;`plan_stage` 的结果里也显示当前计划的这组数字。
5. **提示词**:只改讲 `go`/`route`/`plan_stage` 的几行，说明：去新副本时代码会自动出计划;有计划时 `go` 会被改成按计划走;离开计划要写理由。不加打法建议。

## 测试

- 坐标 go 指向世界地图上一个副本入口(atlas 出口)、没有计划 → 叫了阶段官(替身),出发检查照常;指向普通格 → 不叫;
- 有计划(已出发)时坐标 go 指向计划外的格 → 执行了计划路线(替身执行器记下调用),结果开头有那句话;开关关掉 → 原来的拒绝说明;带 `leave_incomplete` → 放行;
- 地名 go 到达计划覆盖的地图且计划有剩余站 → 同一次调用接着走;遇到 `early` → 提前返回;开关关掉 → 到达即返回;
- 阶段统计的累计和活动日志那一行;
- 倒计时、侦察模式下的现有例外照旧;
- `npm run check` 全过。
