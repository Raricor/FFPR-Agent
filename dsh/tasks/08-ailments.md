# 任务 08:战斗外治状态异常，没法治时告诉模型

先读 `CLAUDE.md`。新功能，只改 TS 版。任务 07(属性)已经合进来。

## 起因(10-27 火力船实测)

- 巴兹和蕾娜一直是「黑暗」。模型在地图 252 的规则表里写了「黑暗 → 道具:眼药」,但**包里没有眼药**,规则一次也没生效。
- 别的地图没写策略，用的是默认规则。
- 也没有任何地方告诉模型「没有眼药，去买或者住店」。
- 战斗外也没有用道具的办法。

## 要做的

### 1. 战斗外用道具:`menu.ts` 加 `useItem(pilot, item, target)`

- 照现有的 `cast`(地图菜单 → 魔法 → 施法者 → 法术 → 目标)来写：地图菜单 → 道具 → 在列表里找到这个道具(翻页)→ 确认 → 选目标 → 确认 → 退回地图。
- 桥插件已经读得到道具菜单(`menu` 查询里的 `item`):
  - `state`、`commandCursor`;
  - `rows`(名字、数量)、`listCursor`;
  - `targets`(名字、HP)、`targetCursor`、`targetMode`。
  - 写法看 `../bridge/src/GameState.Menus.cs` 的 `ItemMenu`。
- 结果文字照 `cast` 的风格，比如「给 蕾娜 用了「眼药」:黑暗 治好了」。没有这个道具、目标不对时说清楚。
- 道具名去掉 `<…>` 图标标记再比较。

### 2. 新工具 `use_item`

- 在 `prompt.ts` 的 `TOOLS` 里加一个:`use_item(item, target)`,中文说明照其他工具的口气:「在地图上给某人用道具，比如用眼药治黑暗、用解毒药治毒」。
- `game.ts` 的 `run` 接上它;`SYSTEM_PROMPT` 里说状态异常的那几行补一句可以用 `use_item`(只加，不改原文)。

### 3. 战后整备用道具

- `battle.ts` 的 `patchUp`:现在只用法术治(`CURES` 的法术那一列)。
- 改成：没有对应法术、或者 MP 不够时，用 `CURES` 的道具那一列，调第 1 条的 `useItem`。
- 战后回复的文字里写出用了什么。

### 4. 没法治的时候告诉模型

- 每次工具结果后面(`game.ts` 那串提示里加一个 `ailmentHint`):
  - 有人带着状态异常;
  - 这个异常包里没有对应道具，也没人会对应法术;
  - 就提示一句，比如「巴兹、蕾娜 黑暗:包里没有眼药，没人会治。去商店买眼药，或者住店」。
  - 如果攻略库(`guide`)查得到附近哪家店卖这个道具，把店名带上。
- **不要每次都说**:异常的组合变了才说，或者每进一张新地图说一次。
- 战斗结果里，条件成立、却因为缺道具做不了的规则，说一次，比如「想用眼药治黑暗，包里没有」。

## 测试

- `useItem`:用 `test/fake-pilot.ts` 模拟道具菜单的状态和回复(形状照 `GameState.Menus.cs`),走一遍正常流程、道具不在第一页、包里没有这个道具。
- `patchUp`:用道具治黑暗;法术和道具都没有时什么也不按。
- `ailmentHint`:第一次说、组合不变不再说、换地图再说一次、治好了不说。
- 战斗结果里「缺道具」那句。
