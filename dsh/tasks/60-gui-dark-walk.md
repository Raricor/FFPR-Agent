## 要做的

### 1. 深色主题(整个窗口)

- 配色集中在一个静态类里，不要散落在各处。建议值:
  - 底色 `#1E1F22`,面板 `#2B2D30`,分隔线 `#3C3F41`;
  - 正文 `#DFE1E5`,次要文字 `#9DA0A8`;
  - 强调色 `#5B9BFF`;
  - 状态色：运行中 `#4CC38A`、警告 `#F2B84B`、出错 `#F2555A`、未运行 `#6F737A`。
- 字体统一 `Microsoft YaHei UI`:正文 10pt,标题 12pt 粗体;等宽内容(日志、状态)用 `Consolas` 9.5pt。
- 顶部状态栏：状态圆点 + 作品 + 运行状态、桥插件版本、连接数、运行时长。现在 `_detailPanel` 里的挂钩、最近按键等字段，挪到“状态”页的卡片里。
- 左侧导航(宽约 140 像素):走路 / 截图 / 按键 / 日志 / 状态。
  - 自绘;选中项左边一条强调色竖条、底色稍亮;鼠标悬停也稍亮。
  - 替掉现在的 `TabControl`:页面切换用导航，不要系统标签头。
- 底部操作条：启动、关闭游戏、截图、安装桥插件。
  - 自绘的扁平按钮，有悬停、按下、禁用三种样子;
  - 危险操作(关闭游戏)用出错色描边。
- 日志、状态：深色的 `RichTextBox`(底色和面板一致，正文色)。
- 按键：深色 `ListView`,表头自绘(`OwnerDraw`),行高适中，隔行底色稍有区别。
- 截图：深色底，图片按比例居中。
- 一作都没开、两作同时开着(现在的 `_emptyLabel`、`_multiPanel`):也改成深色卡片的样子，内容和按钮不变。
- 托盘图标、托盘菜单、单实例、日志跟踪、安装、启动/关闭的行为都不变。
- `AutoScaleMode.Dpi`;最小尺寸可以保持 820×520。
- 双缓冲，避免刷新时闪烁。

### 2. “走路”页

数据来源：桥插件的只读查询 `walk`(任务 59)。只在“走路”页可见、窗口没最小化时，每 250 毫秒问一次，其他时候不问。

```json
{"op": "walk"}
→ {"walk": {
    "seq": 12, "active": true, "map": 30,
    "path": [[5, 8], [6, 8], [7, 8], [8, 8], [9, 8], [9, 9]],
    "goal": [12, 15], "label": "go → 地图 30「图尔村」 第 2 跳",
    "index": 3, "steps": 3, "cell": [8, 8],
    "segment": {"n": 1, "of": 2, "from": [5, 8], "to": [9, 8]},
    "turns": [{"cell": [9, 8], "at": [8.42, 8.01], "frame": 123456, "ok": true}],
    "startedAt": "2026-11-05T05:12:03.120Z", "endedAt": null, "reason": null
  }}
```

- 一条都没走过时是 `{"walk": null}`;旧桥插件不认识 `walk`,会回错误。这两种情况都显示一句说明，不要报错弹窗。

**地图底图**(只读查询，每张图缓存一次，换图或换 `seq` 时按需再读):
- 室内用 `collision`:`layers[i].rows` 是一行一个字符串，一格一个字符;`searchLayer` 是当前层。
  - 画当前层：字符 `0` 是地板;`2`、`3`、`4`、`5` 也能走，画成稍暗的地板;其他是墙。
- 世界地图(`collision` 报错或没有 `layers`)用 `cells`:`attr` 是地形码，`origin` 是窗口左上角。
  - 窗口有 `at` 参数，以路线范围的中心读，`r` 最大 24;路线超出一个窗口时最多读 4 个窗口拼起来。
  - 颜色:16 是海(深蓝);19、27 是山(灰褐);3、4 是平原、草地(暗绿);其他陆地中性暗色;null 是底色。
- 底图读不到就只画路线，不要因此不画。

**画法**(自绘控件，双缓冲):
- 视野：路线和目标的包围盒外扩 3 格，等比缩放铺满，格子保持正方形;格子太小时不画格线。
- 路线分三种画法:
  - 已走过的：次要文字色点线;
  - **正在走的那一段**(`segment.from` → `segment.to`):强调色粗线;
  - 还没走的：强调色半透明虚线。
- 拐角：小圆点;`turns` 里 `ok: false` 的(冲过头又走回来)画警告色叉。
- 人在 `cell` 上画实心圆;`goal` 画空心圆环;`goal` 不在路线终点时，从终点到目标画一条很淡的虚线。
- 右侧信息栏(宽约 220 像素):
  - `label`、地图号;
  - 第 n/of 段、这一段的起点→终点;
  - 已走 steps / 总格数、拐角数和其中“不停”的个数(`ok: true`);
  - 已用时间和每格秒数(结束时用 `endedAt`,没结束用现在);
  - 状态：走着就写“正在走”,结束了写停下原因的中文:arrived 到达、battle 遇敌、dialog 对话、`state:Event` 剧情、`state:*` 其他状态(把 * 原样写出)、map_changed 换图、blocked 被挡住、off_path 偏离路线、timeout 超时、stopped 停止、closed 连接断开、bad_path 路线无效、no_player 读不到人物。
