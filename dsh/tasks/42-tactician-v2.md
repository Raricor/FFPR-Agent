# 任务 42:战术官 2.0:敌人档案、队伍能力、2.0 规则表、覆盖面检查、首领前准备、战后复盘

范围:
- `src/engine/`(`facts.ts`、`game.ts` 里战术官相关的部分、`prompt.ts` 的战术官提示词，以及新文件，例如 `dossier.ts`)、`src/plugin/tactician.ts`、`test/`;
- 不改 `src/engine/skills/battle.ts`、`skills/grind.ts`、`src/engine/strategy/` 的语言规格(可以调用它)、`src/client/`;
- 不改 `package.json`、`tasks/`、`lib/`、`../agent/`、`../bridge/`、`../deploy/`;
- 不碰 git;不 build;不运行 `scripts/web.sh`、`ask.mjs`;不连笔记本。
- 检查:`flock /tmp/ffpr-heavy.lock npm run check`。
- **分段做**，每段检查一次：
  1. 敌人档案和队伍能力;
  2. 2.0 规则表和覆盖面检查;
  3. 换职业重查、首领前准备、战后复盘。

## 起因

- 风之神殿的巨翼猛禽：战术官写“只会普通攻击，全队平砍”，因为它不知道这只怪会合翅膀反击。
- 北山的玛基莎：首领是走到剧情格时自动开打的，战术官开打后才说“只剩 1 根不死鸟之尾，建议先回镇补货”，已经晚了。
- 世界地图那套表是法利斯当黑魔法师时写的，他换成武僧以后，第 1 条“黑魔法:火炎”每次都跳过(没有这个指令)。规则表从来不会因为换职业失效。
- 执行器 2.0(任务 41)已经能按阶段、对策执行，可战术官和手动 `fight` 还只会写旧格式的表。

## 要做的

### 1. 敌人档案和队伍能力(资料单)

- **敌人档案**，一只怪一段：
  - 能力值、弱点、吸收、免疫(现在的图鉴资料和属性记录);
  - 会用的招：
    - 桥插件 0.13 的 AI 脚本(`monsterai`,带每招概率和分组);
    - 实战见过的(`battle.act`);
  - 反击、变身(不同编号的形态);
  - 攻略里讲它的句子(`monsterNote`,任务 34);
  - 上次和它打的摘要(战斗记录：结果、缺口、它用过的招)。
- **AI 脚本存下来**：引擎在战斗开始、或者第一次见到某只怪时查一次 `monsterai`,结果存进 `.deps/ds/monsterai-<作品>.json`,以后不在战斗里也能用。
  - 桥插件推的 `battle.ai` 事件也要收。
  - 桥插件版本早于 0.13 或者查不到时，就跳过。
- **队伍能力**：每个人的职业、指令、学会的能力、MP、装备;背包里能回复、复活、治状态的道具和数量。

### 2. 2.0 规则表和覆盖面检查

- 战术官提示词改成用 2.0 格式写:`roles`、`reactions`、`phases`、`note`。附上两个完整例子(巨翼猛禽、玛基莎，见 `test/fixtures/strategy/`)。旧格式仍然接受。
- 战术官交回的表，`checkStrategy` 之后，再做**覆盖面检查**，不通过就打回并列出缺什么(沿用现在最多重试 2 次的机制):
  - 至少两个人能复活，或者背包里有足够的不死鸟之尾;
  - 有回复手段;每个靠魔法的人，MP 不够时有退路;
  - 敌人档案里会造成的每种状态，都有对应处理，而且道具真的有(不够的写进建议);
  - 档案里标了反击 / 变身 / 吸收的，规则里要有阶段或对策提到它;
  - 每条规则用到的指令，行动的人**现在**真的有(职业指令对得上)。
- 手动 `fight` 也接受 2.0 格式。

### 3. 换职业重查、首领前准备、战后复盘

- **规则表记下写表时的队伍**：每人的职业、指令。
  - 换了职业、学了新能力以后，下次用到这套表时，先按现在的指令检查一遍;
  - 有规则用不了，就触发战术官重写(新的触发类型，例如 `party-changed`),原因写清楚，例如「法利斯从黑魔法师换成了武僧，第 1 条 黑魔法:火炎 用不了」。
- **首领前准备**：进入攻略里标了首领的地图时(或者 `look_around` 看到首领事件格时)，先叫一次战术官，触发类型 `boss-prep`:
  - 资料单带上首领的敌人档案、队伍能力和背包;
  - 让它写首领表，并在 `ask_up` 里写明缺什么(补给、职业、装备)、要不要先回城;
  - 首领表按地图存好，开打时直接用，开打那一刻不必再从头写。
- **战后复盘**：普通战斗打得吃力或全灭、首领战全灭以后，叫战术官改表时，资料单带上这一场的战斗记录摘要：
  - 每条规则触发几次、跳过几次、为什么;
  - 缺口;
  - 敌人用了哪些招;
  - 谁先倒的。

## 测试

- 敌人档案：有 AI 脚本、实战见过的招、攻略句子时都能列出来;AI 脚本缓存能存能读;
- 覆盖面检查：缺复活、缺治状态的道具、没提反击 / 变身、指令对不上，各自打回;
- 换职业后，触发 `party-changed`;
- `boss-prep` 在进首领地图时触发一次，首领表存下，开打时直接用;
- 复盘的资料单里有战斗记录摘要;
- 旧格式照样能用。

`npm run check` 全过，测试数不能比现在少(现在是 617 个)。
