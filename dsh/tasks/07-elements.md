# 任务 07:属性(弱点、吸收)进入战斗决策

先读 `CLAUDE.md`。这是**新功能**,不是移植:只改 TS 版,Python 版不动。`tasks/port-rules.md` 里关于中文文字、注释、测试的规矩照样适用。

## 起因(10-27 火力船实测)

- 法利斯按默认规则「黑魔法:最强」放冰冻，打在一只吸收冰的怪身上，怪回血了。
- 「最强」只挑「会的、MP 够的最高一级」,完全不看敌人的属性;模型在规则表里也看不到敌人怕什么、吸收什么。

## 要做的

### 1. 属性知识 `src/engine/elements.ts`(新)

- 每只怪(按图鉴编号 `book`,没有就按名字)记三样：弱点、吸收、无效，属性用中文单字：火 冰 雷 水 风 土 圣 毒。
- 来源有两个，都要合进来:
  - **攻略**:`.deps/knowledge/ff5/` 的 ludo 页面里，敌人行写成「037 Crew Dust (Level 17, HP 240): … Weak to Ice, Water, Wind.」。在 `guide/ludo.ts` 里解析出每只怪的弱点;看到 Absorb、Immune、Null 这类写法也一并解析(先 grep 全部缓存页面，看实际有哪些写法)。英文属性名换成中文单字。
  - **实战学到的**:见第 2 条。存到 `DEPS/ds/elements-ff5.json`(和地图记录、战术放一起),格式自定，异步读写。

### 2. 战斗里学：打了才知道的吸收

- 执行规则表时，记下每次属性魔法(按 `gambit.ts` 的 `FAMILIES`:火炎系=火、冰结系=冰、闪雷系=雷)打在哪个敌人身上、打之前它的 HP。
- 下一次读到战斗菜单时比较那个敌人的 HP:**变多了就是吸收**,记进知识库并存盘。
- 同一场战斗里立刻生效(后面的回合不再对它放这个属性)。
- 战斗结束的文字里说出来，比如「败怨魔 吸收冰,以后不对它用冰」。

### 3. 挑法术时看属性

- 「最强」和「X+」(`abilityCandidates`)按**当前目标**过滤:
  - 去掉目标吸收的、无效的属性;
  - 剩下的里面，目标弱的属性优先，再按原来的顺序。
- 全部被去掉时，这条规则做不了(`CannotDo`),交给下一条规则，和现在「不会、MP 不够」一样处理。
- 规则表里写死的具体法术(如「黑魔法:冰结」),目标吸收这个属性时也不放，同样交给下一条，并在战斗结果里说一句。

### 4. 让模型看得到

- **规则表的词汇**(`gambit.ts` 的 `VOCABULARY`):
  - 加 `enemy.weak.<属性>`:有几只敌人弱这个属性;
  - 加 `enemy.absorbs.<属性>`:有几只敌人吸收这个属性;
  - `check()` 认这两个前缀，报错文字照现有风格。
- **首领战的局面描述**(`prompt.ts` 的 `describeBattle`):每只敌人后面标出已知的属性，比如「败怨魔(弱 冰;吸收 —)」;不知道就不标。
- **工具说明**(`prompt.ts` 的 `TOOLS` 里 `fight`、`set_tactics` 的描述)和 `SYSTEM_PROMPT` 里讲规则表的那几行：补一句「最强」会自动避开敌人吸收的属性、优先弱点，以及新词汇的用法。只加，不改原有文字。

## 测试

- 攻略解析：用真实缓存页面导出几只怪的弱点(火力船那页至少有 Crew Dust、Poltergeist、Defeater、Motor Trap、Liquid Flame)。
- 吸收的学习：用 `test/fake-pilot.ts` 做一场战斗：放冰之后那个敌人 HP 变多 → 记下吸收、存盘、下一回合改用别的属性或下一条规则。
- 挑法术：弱点优先、吸收的跳过、全部跳过时交给下一条规则、写死的法术被吸收时也跳过。
- 词汇：`enemy.weak.冰` 和 `enemy.absorbs.冰` 的求值和 `check()`。
