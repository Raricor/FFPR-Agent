# 任务 110:玩家手写的战斗表优先——离开这张图之前不被战术官覆盖

工作目录 `dsh/`。可以改 `src/engine/game.ts`、`src/engine/tactics.ts`、`src/engine/facts.ts`、`src/plugin/tactician.ts`、`src/engine/prompt.ts`(只改 `set_tactics` 那一句说明)、`test/`。不碰 `../bridge/`、`../deploy/`、`../agent/`,不碰 git,**不连笔记本**,**不用 docker、不绕开沙箱**。

## 起因(待办 63,用户 11-10 定的)

- 11-05 西侧山谷:AI 用 `set_tactics` 给一张图手写了战斗表，战术官下次触发(新怪、打得不好等)时把它静默换掉了，AI 在总结里抱怨。按设计 `set_tactics` 是手动覆盖。
- 用户定：**手写的表优先，直到离开这张图;离开后战术官再接管。**
- 任务 86 起，路上触发战术官改成后台写表(`Game` 里的后台调用、`applyPlan`/装表);首领表(`boss-prep`、任务 106 出发前写的首领表)另有一套。

## 做法

1. **记下“手写”**:`set_tactics` 写的表在 `tactics` 里带上来源标记(比如 `source: "player"`)和写的时刻、写在哪张图。
2. **在这张图上不被覆盖**:人还在这张图上时，战术官的路上触发(新图、新怪、被挡、被带走、队伍变化、打得不好):
   - 不发起写表(省钱);只有“打得不好(hard / lost)”时可以照常发起，但**写好的表不装上**,而是把战术官的说明和建议附在下一次工具结果里，写明“你手写的表还在用;战术官建议……,要换就自己 `set_tactics`”;
   - 后台已经在写、写完时人还在这张图上 → 同样不装上，只附说明。
3. **离开后接管**:人离开这张图(进了别的图)以后，这张图的手写标记作废;下次回到这张图、触发战术官时照常写表、装上。
4. **首领不受影响**:首领表照旧(首领战用首领表);手写的普通战斗表不影响首领表，首领表也不覆盖手写的普通战斗表。
5. 工具结果:`set_tactics` 成功时说明“在离开这张图之前，战术官不会覆盖这张表”。
6. 提示词里 `set_tactics` 那句补半句同样的说明(只改这一句)。

## 测试

- 手写表后，同一张图上遇到新怪 → 不叫战术官，表不变;
- 同一张图上打得不好 → 战术官写了，但表不变，结果里附建议;
- 后台写完时还在这张图 → 不装上;
- 离开再回来 → 触发战术官时照常装上;
- 首领表与手写表互不覆盖;
- `npm run check` 全过。
