# 任务 21:六作同时玩：每作一个 DeepSeek 玩家

先读 `dsh/CLAUDE.md` 和 `dsh/tasks/20-six-games-panel.md`。只改 TS(`src/engine`、`src/plugin`、`test`)和本目录的 `cordis.patch.yml`。不改 `../bridge/`、`../deploy/`、`../agent/`(Claude 来改)。不碰 git,不装 profile。

## 起因

用户今天的目标：六作同时玩起来，每作一个 DeepSeek 玩家。

- 笔记本上六作可以同时开(10-28 实测，各自约 60 帧)。
- 桥插件 0.10.0 起端口按作品分开:FF5 47800,FFN 4780N(FF1 47801 … FF6 47806)。
- 局域网防火墙已按这些端口放行。

现在的插件只会玩 FF5:配置、提示词、工具、存档位、试玩助手都按 FF5 写死。

## 用户定下的规矩

- **FF5** 照旧：存档只写 3 号位。
- **FF1–FF4、FF6**:从新游戏开始(Claude 会先把开头的起名画面过掉，交给玩家时人物已经能走),存档只写 **20 号位**,绝不碰别的存档位。
- 五作也要有战术官(第二层),和 FF5 一样替玩家写规则表。

## 1. 配置按作品给默认值(`src/plugin/config.ts`)

- 新增 `saveSlot`,不填时 FF5 是 3,其他是 20。
- 不填 `bridgeUrl` 时，端口按作品:FF5 47800,FFN 4780N。
  - `laptop.env` 里的 `BRIDGE_URL` 只对 FF5 有效(它写的是 47800)。
- `notesFile`、`atlasFile`、`tacticsFile` 不填时按作品：`.deps/ds/notes-<game>.json` 等。FF5 的路径不变。
- 认不出的 `game` 报错(用 `games.ts`)。
- 写成一个函数，例如 `gameDefaults(game)`,配置和测试共用。

## 2. 试玩助手每作一份(`src/engine/link-pilot.ts`)

- `agentDir(laptop)` 改成 `agentDir(laptop, game)`:
  - FF5 照旧 `<root>/session/pilot`(Python 版也用这个);
  - 其他是 `<root>/session/pilot-<game>`。
- `startAgent` 已经传 `-Game`。`pilot-agent.ps1` 会按同样的规则选目录、选端口(Claude 改)。
- 所有用到 `agentDir` 的地方都按引擎自己的作品传。

## 3. 存档位(`skills/save.ts`、`game.ts`、`prompt.ts`)

- `save_game` 和读档都用配置的 `saveSlot`,不再写死 3。
- `save_game` 的工具说明写成「存档到 N 号存档位」。
- `saveGame` 现有的「确认前核对光标停在哪个存档位」保留：光标不在 `saveSlot` 就不按确定，报错。

## 4. 预设：每作一个玩家、一个战术官(`cordis.patch.yml`、`src/plugin/tactician.ts`)

| 作品 | 玩家预设 id / 名字 | 战术官预设 id / 名字 |
| --- | --- | --- |
| FF5 | `ffpr` / FF5 玩家(不变) | `ffpr-tactician` / FF5 战术官(不变) |
| FFN(1–4、6) | `ffpr-ffN` / FFN 玩家 | `ffpr-tactician-ffN` / FFN 战术官 |

- 每个玩家预设的插件配置写 `game: ffN`;战术官预设写 `role: tactician` 和 `game: ffN`。
- `TACTICIAN_PRESET` 改成按作品取 id 的函数，玩家叫起的是自己那一作的战术官。
- 面板入口(`ffpr-panel`)只留一个。

## 5. 提示词按作品(`src/engine/prompt.ts`)

`SYSTEM_PROMPT`、`TACTICIAN_PROMPT` 改成函数 `systemPrompt(game)`、`tacticianPrompt(game)`。

### FF5

- 输出和现在的常量**一字不差**。
- 加对照测试，把现在的常量原样存成 fixture。

### 其他五作

- 开头一句换成「你在玩《<中文名> 像素重制版》(中文版)」。中文名：
  - FF1 最终幻想;
  - FF2 最终幻想II;
  - FF3 最终幻想III;
  - FF4 最终幻想IV;
  - FF6 最终幻想VI。
- 只在 FF5 出现的行要去掉：
  - 飞龙(board、land);
  - 换职业(change_job);
  - 「中文版的魔法名」那一行;
  - 用魔法回 HP(cast);
  - 规则表里讲魔法、「最强」「X+」、属性的行;
  - 攻略(guide)相关的行;
  - 「魔法要先在魔法店买到」那一行。
- 加一段「这一作的要点」,用下面的原文。
- 加一行：「游戏已经开好新游戏、过了起名，从现在的位置开始玩;第一次能存档时就用 save_game 存档。」

**FF1 的要点**

```
- 四个光之战士，职业在开局定好;剧情后半有一次转职。
- 魔法按 1–8 级分，每级每人最多学 3 种，在城镇的白魔法店、黑魔法店买，只有对应职业能学。
- 第一个目标：科内利亚的国王要你去西北的混沌神殿救公主。
```

**FF2 的要点**

```
- 没有等级：挨打多了涨 HP,用武器涨那种武器的熟练度，用魔法涨 MP 和那种魔法的熟练度。
- 关键词：有人说出新词时，游戏会让你「记住」;要在对的人那里「询问」这个词，剧情才会往下走。选项里出现记住、询问时照剧情选。
- 开头那场战斗打不赢，全灭以后剧情会接着走，这是正常的。
```

**FF3 的要点**

```
- 四个洋葱剑士。拿到水晶以后可以转职，但这里还不能用工具转职，先用初始职业打。
- 开局在祭坛洞窟里，先找出口。有的地方要变小(迷你)或变青蛙才进得去，攻略和剧情会提示。
```

**FF4 的要点**

```
- 主角塞西尔，队友由剧情决定，会加入也会离开;不能转职，每人的能力固定。
- 战斗是即时的(ATB),行动要快;队伍变动时注意看重要事件里的入队离队。
```

**FF6 的要点**

```
- 角色很多，剧情会把队伍分成几路;魔法靠魔石(幻兽)学。
- 开局在炭坑都市纳尔谢，先跟着剧情走。
```

### 五作的战术官提示词

- 规则表的写法(结构、条件词汇、兜底规则、target)照 FF5 的版本。
- 「do」只能写「攻击」「防御」「道具:道具名」。
  - 原因：桥插件在这五作里读不到战斗中的魔法列表。
  - 写明「这一作的魔法和特技暂时不能写进规则表」。
- 去掉 FF5 的职业、魔法名、属性魔法、「最强」「X+」、换职业建议。
- 状态异常要的道具名用通用说法(解毒药、眼药、金针等),写明「以游戏里的道具名为准」。
